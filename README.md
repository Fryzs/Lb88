# Погодження документів — патерн «Ланцюжок обов'язків»

Лабораторна робота на Windows Forms (.NET), що демонструє патерн **Chain of Responsibility**.

## Як працює

Користувач вводить назву документа та суму і відправляє його на погодження. Документ проходить ланцюжок обробників:

1. **Менеджер** — погоджує суми до 1 000;
2. **Бухгалтерія** — погоджує суми до 10 000;
3. **Директор** — ухвалює остаточне рішення щодо більших сум.

Кожен крок відображається у списку на формі.

## Запуск

Відкрийте `Lb8.sln` у Visual Studio і натисніть F5.
